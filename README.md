# 📱 SocialSphere - A Modern Social Media Application

**SocialSphere** is a full-featured social media platform developed using **Spring Boot** and **React JS**. It allows users to register, log in, create posts with images, like and comment on posts, and interact with others in a clean, modern UI.

## 🚀 Features

- User Registration & Login (JWT-based authentication)
- Create, edit, delete posts with image uploads
- Like and comment on posts
- View posts from followed users
- Follow and unfollow users
- Real-time feed updates (WebSocket-ready)
- Responsive UI using modern design

## 🧰 Tech Stack

### 🌐 Frontend

- React JS
- Axios
- React Router
- Ant Design abd Tailwind css

### 🔙 Backend

- Spring Boot (Java)
- Spring Security + JWT
- Spring Data JPA (Hibernate)
- MongoDB
- RESTful APIs

### 🗄️ Storage

- Image Upload: Local server storage
